# Pipeline overview

The pipeline has three parts, all built on one study population:

1. Study population (`inex`) - everyone who could be eligible at any point in the study period.
2. Covariates and outcomes (`cov` + `out`) - used for Table 1, the descriptive tables, the cumulative incidence plots and the survival analysis.
3. Prescription gaps (`hist`) - used for the histograms of gaps between prescriptions.

The `cov`, `out` and `hist` datasets are generated using one action per study year. Each yearly dataset contains the patients eligible on 1 January of that year. The cleaning step then stacks the years into one dataset with one row per patient per year (with a `year` column), which is what the analysis scripts use.

`project.yaml` is generated by [`analysis/create_project_yaml.py`](./analysis/create_project_yaml.py). To change the study years, edit [`analysis/config.json`](./analysis/config.json) and re-run.

# File details

- The most recent version of the protocol can be found in the [`protocols`](./protocols/) folder.

- The [`codelists`](./codelists) folder contains [`codelists/codelists.txt`](./codelists/codelists.txt), a full list of all codelists used in this project. Each of the .CSV for those codelists can also be found in this folder.

- [`project.yaml`](./project.yaml) lists all actions to be run in OpenSAFELY and their run order. It is generated by [`create_project_yaml.py`](./analysis/create_project_yaml.py).

- The data in [`dummy_tables`](./dummy_tables) was generated using a combination of R scripts and manual data entry. The scripts used will be added to the main branch in a later push.

The following scripts are in the [`analysis`](./analysis) directory:

- [`config.json`](./analysis/config.json) contains the study start and end dates. 
- [`create_project_yaml.py`](./analysis/create_project_yaml.py) writes `project.yaml`.
- [`utility.R`](./analysis/utility.R) contains miscellaneous functions used in the analysis (midpoint 6 rounding, describing datasets, helpers for the Cox models).

**Dataset definitions** - [`dataset_definition`](./analysis/dataset_definition/)

- [`dataset_definition_inex.py`](./analysis/dataset_definition/dataset_definition_inex.py) - inclusion/exclusion and QA variables for everyone who could be eligible at any point in the study period.
- [`dataset_definition_cov.py`](./analysis/dataset_definition/dataset_definition_cov.py) - covariates that could be predictors of medication reviews or stopping, for one study year.
- [`dataset_definition_out.py`](./analysis/dataset_definition/dataset_definition_out.py) - outcomes (medication reviews, stopping of each antihypertensive class for each gap size) and censoring dates (death, deregistration), for one study year.
- [`dataset_definition_hist.py`](./analysis/dataset_definition/dataset_definition_hist.py) - counts of gaps between prescriptions and practice region, for one study year.
- The `cov`, `out` and `hist` definitions take the study year as a parameter (`-- --year YEAR` in `project.yaml`), and their population is everyone in the cleaned `inex` dataset who is eligible on 1 January of that year.
- [`add_variables.py`](./analysis/dataset_definition/add_variables.py) contains functions for the inclusion/exclusion criteria and covariates.
- [`variable_helper_functions.py`](./analysis/dataset_definition/variable_helper_functions.py) contains helper functions, including the stopping-date and prescription-gap functions.
- [`codelists.py`](./analysis/dataset_definition/codelists.py) loads each codelist that is needed.

**Cleaning** - [`dataset_clean`](./analysis/dataset_clean/)

- [`dataset_clean_inex.R`](./analysis/dataset_clean/dataset_clean_inex.R) cleans the `inex` dataset: quality assurance, inclusion/exclusion criteria and the flow chart counts.
- [`dataset_clean.R`](./analysis/dataset_clean/dataset_clean.R) cleans the yearly datasets. It takes the dataset type (`cov`, `out` or `hist`) and whether to write describe files, reads each year's file, stacks them into one row per patient per year, and sets factor levels.
- [`fn-load_data.R`](./analysis/dataset_clean/fn-load_data.R) loads a raw dataset and formats the columns based on their names.
- [`fn-qa.R`](./analysis/dataset_clean/fn-qa.R) is the quality assurance function.
- [`fn-inex.R`](./analysis/dataset_clean/fn-inex.R) applies the inclusion and exclusion criteria.
- [`fn-ref.R`](./analysis/dataset_clean/fn-ref.R) handles missing values and sets the factor and reference levels.

**Analysis** - [`tables`](./analysis/tables/)

- [`create_table1_cov.R`](./analysis/tables/create_table1_cov.R) creates Table 1 (patient characteristics, and the number who had a medication review) for each year and pooled across years. Uses [`fn-table1_functions.R`](./analysis/tables/fn-table1_functions.R).
- [`create_table_desc.R`](./analysis/tables/create_table_desc.R) creates a table of the number of eligible patients, patients with a medication review and medication reviews, by region and year.
- [`create_table_cum_inc_med_rev.R`](./analysis/tables/create_table_cum_inc_med_rev.R) creates the cumulative incidence of medication reviews by year (table, and plots for viewing in OpenSAFELY).
- [`create_table_cum_inc_stop_any.R`](./analysis/tables/create_table_cum_inc_stop_any.R) creates the cumulative incidence of stopping any antihypertensive by year, for each gap size (table, and plots for viewing in OpenSAFELY).
- [`create_survival_analysis.R`](./analysis/tables/create_survival_analysis.R) fits univariable and multivariable Cox models for medication review and stopping, for each year.
- [`create_table_prescription_gaps.R`](./analysis/tables/create_table_prescription_gaps.R) creates the table of gaps between prescriptions by year and region, used for the histograms.
- [`create_frailty_table.R`](./analysis/tables/create_frailty_table.R) is a frailty coverage investigation. It is not currently run (its action is commented out in `project.yaml`).

**Variable naming**

Variable names start with a prefix showing what they are and their type, e.g. `cov_cat_region`:

- `inex_` inclusion/exclusion criteria, `qa_` quality assurance, `cov_` covariates, `out_` outcomes, `cens_` censoring dates.
- `_bin_` binary, `_cat_` categorical, `_num_` numeric, `_dat_` date. The cleaning scripts use these to set the column types.
